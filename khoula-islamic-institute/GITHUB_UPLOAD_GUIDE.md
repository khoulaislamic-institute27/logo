# Khoula Islamic Institute — GitHub & Vercel Update Guide

Aapki website mein **Khoula Islamic Institute** ka official logo mukammal tor par integrate ho chuka hai. 

Tamam updated files in dono folders mein available hain:
- 📁 **Active Project Folder:** `D:\kii\khoula islamic institute kii`
- 📁 **Desktop Backup Folder:** `C:\Users\INDUS\Desktop\khoula-islamic-institute`

---

## ⚠️ Vercel par Logo kyu show nahi ho raha tha?
Pehle jab files upload ki gayi theen, to unme `images` ka folder aur updated files shamil nahi theen. Vercel par logo dikhane ke liye **`images/` folder** ka GitHub ya Vercel par hona lazmi hai.

---

## 🚀 Tareeqa 1: GitHub ke Zariye Vercel Update Karein (Recommended)

Agar aapki Vercel website GitHub se connected hai:

1. Apne browser mein [GitHub.com](https://github.com/) open karein aur login karein.
2. Apni repository kholain: `khoula-islamic-institute` (ya jo bhi naam aapne rakha tha).
3. **`Add file`** button par click karein aur **`Upload files`** select karein.
4. Apne computer ke folder (`D:\kii\khoula islamic institute kii` ya `Desktop\khoula-islamic-institute`) se tamam files aur **`images` folder** ko drag karke GitHub ke box mein drop karein:
   - 📁 **`images/`** *(Bohut zaroori: isme logo aur favicon hain)*
   - 📄 `index.html`
   - 📄 `student-portal.html`
   - 📄 `admin.html`
   - 📄 `styles.css`
   - 📄 `app.js`
5. Neeche commit message likhein: `Add official Khoula Islamic Institute logo and assets`.
6. **`Commit changes`** par click karein.
7. **Bas!** Vercel automatic 10 se 20 seconds ke andar nayi build deploy kar dega aur aapki live link par logo nazar aane lagega!

---

## ⚡ Tareeqa 2: Vercel Dashboard par Direct Redeploy

Agar aapne GitHub ke baghair direct Vercel par project banaya tha:

1. [Vercel Dashboard](https://vercel.com/) open karein.
2. Apne project par click karein (`kola-islamic-institute` / `khoula-islamic-institute`).
3. Deployments tab mein ja kar new deployment upload karein ya repo ko sync karein.

## 🖼️ Website par Kahan Kahan Logo Add Hua Hai?

1. **Top Navigation Header:** Header mein left side par official arch + *kii* calligraphy logo transparent background ke sath lag chuka hai.
2. **Dark Footer:** Footer mein luxury gold-bordered white badge container ke andar logo laga diya gaya hai.
3. **Browser Tab (Favicon):** Tab ke sath official institute icon nazar aayega.
4. **Student Portal & Certificates:** Student classroom topbar aur completion certificate ke official seal par logo laga hua hai.
5. **Admin Portal:** Passcode verification screen aur sidebar menu dono par logo update hai.
